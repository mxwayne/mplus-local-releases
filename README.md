# M+提醒

本地素材审核状态监测与桌面提醒。

[下载最新版本](https://github.com/mxwayne/mplus-local-releases/releases/latest) · [查看历史版本](https://github.com/mxwayne/mplus-local-releases/releases)

本仓库用于分发安装包与版本更新。当前已发布 Windows 版本；macOS 版本以对应 Release 实际提供的附件为准。

## 安装包命名

- Windows：`m-plus-local-reminder-<版本>-windows-<架构>-setup.exe`
- macOS：`m-plus-local-reminder-<版本>-macos-<架构>-setup.dmg`

架构使用 `x64` 或 `arm64`。新命名用于后续版本，历史安装包保持原名。
